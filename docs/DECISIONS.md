# Architecture Decision Records

Format: context → decision → alternatives → consequences. Status: **Accepted**, **Proposed** (awaiting owner
approval) or **Superseded**.

## ADR-001 — Monorepo with `apps/` per deployable — Accepted
- **Decision:** one repository: `apps/flashcart-api`, `apps/flashcart-web`, later `apps/sentinel*`, shared `docs/`, `scripts/`.
- **Why:** one CI pipeline, atomic changes across API + UI, single source of documentation.
- **Consequence:** CI uses path filters so a web-only change doesn't rebuild the API.

## ADR-002 — FastAPI + PyMongo native async client — Accepted
- **Decision:** PyMongo ≥4.10 `AsyncMongoClient` (not Motor). Motor is being superseded by PyMongo's own async API.
- **Consequence:** one driver for sync scripts and the async app; transactions via `session.with_transaction`.

## ADR-003 — Money as integer paise — Accepted
- **Decision:** all amounts are integers in paise (₹1 = 100 paise); the server computes every total.
- **Why:** no floating-point rounding errors; client totals are never trusted.

## ADR-004 — Supply-chain cooldown (14 days) with a security-fix exception — Accepted
- **Decision:** adopt only package/tool versions published ≥14 days ago: uv `exclude-newer`, npm `before` +
  exact pins, CLI versions pinned in `install-tools.ps1` with SHA-256 verification, CI check
  `scripts/ci/check-npm-age.py`. **Exception:** a version that fixes a known vulnerability may be newer; it must be
  listed in `scripts/ci/npm-age-exceptions.txt` with the advisory ID.
- **Why:** most malicious package releases are detected and yanked within days.
- **Alternatives:** always-latest (fast but exposed), manual review only (doesn't scale).

## ADR-005 — Same-origin SPA + API — Accepted
- **Decision:** browser always talks to one origin: Vite proxy in development, CloudFront path routing (`/api/*` →
  Lambda) in production.
- **Why:** no CORS surface in production, and the refresh cookie can be `SameSite=Strict`.

## ADR-006 — Token design — Accepted
- Access JWT (15 min, HS256, `kid` for key rotation, in memory only) + opaque refresh token (HttpOnly,
  SameSite=Strict, path `/api/v1/auth`, rotated on every use, reuse → whole family revoked, 10 s grace for benign
  multi-tab races). Role and `session_version` re-read from the DB on every request so revocation is immediate.
- **Trade-off:** one DB read per authenticated request (acceptable; indexed by `_id`).

## ADR-007 — Checkout as one MongoDB transaction + idempotency key — Accepted
- **Decision:** conditional stock decrements (`stock >= qty`) + order insert + cart clear in one ACID transaction;
  `Idempotency-Key` header with a unique index on `(user_id, idempotency_key)`.
- **Alternatives:** Saga with compensations (documented as a lab — needed only when data spans services).
- **Verified by:** 20-buyer race test (exactly 5 of 5 units sold) and 10× duplicate-submit test (exactly 1 order).

## ADR-008 — Portable local MongoDB replica set for dev/tests — Accepted
- Official MongoDB 8.0.34 zip on D:, single-node replica set `rs0` (needed for transactions), bound to 127.0.0.1.
- Atlas M0 for hosted environments (Phase 4). Tests never touch Atlas (protects the 100 ops/s quota).

## ADR-009 — Deployment target: AWS Lambda (Function URL) + S3 + CloudFront — Proposed
- Chosen by the owner. API on Lambda via Mangum behind CloudFront; Function URL avoids API Gateway charges;
  CloudFront injects a secret `X-Origin-Verify` header so the origin rejects direct traffic.
- **Pending:** AWS account details and owner approval of the exact resource list and cost-risk report (Phase 7–8).

## ADR-012 — Hybrid rate limiting — Accepted
- In-process token bucket for general traffic (no DB cost), MongoDB fixed-window counter for login/signup (global).
- **Known limit:** per-instance buckets on Lambda; global ceiling comes from Lambda reserved concurrency.

## ADR-013 — Stay one major version behind on two packages — Accepted
- TypeScript 6.0.3 (typescript-eslint peer range `<6.1`), React Router 7.18.4 (v8 APIs not yet verified here).
- Revisit when typescript-eslint supports TS 7.

## ADR-014 — Isolated end-to-end stack — Accepted
- Playwright starts its own API (port 8001, DB `flashcart_e2e`) and web server (5174). The reset script refuses any
  database not ending in `_e2e`. The e2e admin password is generated per run and never stored.
